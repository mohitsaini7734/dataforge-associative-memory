How much can a fixed-size memory remember?

Associative memory & fast weights, made interactive — with a direct line to Dragon Hatchling (BDH) and BDH-CQ.

The one-sentence claim this explainer teaches

A fixed-size associative memory can store many key→value pairs using simple additive (Hebbian) writes and correctly retrieve them from noisy cues — but because every pair shares the same memory, packing in more pairs raises cross-talk interference, and retrieval accuracy degrades smoothly and predictably — as a continuous function of how many pairs share the memory, not as a sudden collapse at a fixed capacity.

Who this is for, and the 60-second test

Audience: anyone comfortable with a dot product and a matrix–vector multiply — no prior knowledge of Hopfield networks or BDH assumed. Learning objectives: after this page you should be able to (1) explain how an outer-product associative memory writes and reads, (2) predict how retrieval accuracy changes as more patterns share one memory, and (3) name one concrete way BDH/BDH-CQ's real memory differs from this toy.

60-second reproducible test: leave noise at 0% and drag N from 1 to 40. Accuracy will not hold flat and then fall off a cliff — it declines smoothly and monotonically the whole way, from ~100% near N=1 to roughly 90% by N=40 (for d=64), because this demo does a single matrix-vector readout rather than repeated clean-up iterations. (A hard capacity "wall" only appears in the classical iterative Hopfield network, which repeatedly re-reads its own output — a different, stronger dynamic than the single-pass memory built here. That distinction is itself part of the lesson — see the misconception note below.)

What's actually happening: each stored pair (kᵢ, vᵢ) is written additively: W += vᵢ · kᵢᵀ. To retrieve, the memory is probed with a cue: v' = sign(W · cue). When N is small, the "self term" for pattern 1 dominates and retrieval is clean. As N grows, the sum of all other patterns' outer products becomes cross-talk noise sitting on top of the signal you want — same memory, more interference, no new capacity added.

Explain it back (self-check)

Before you scroll further: in 1–2 sentences, explain to yourself why accuracy fell where it did. Then reveal a reference answer and compare — don't just recognise it, check whether your own wording captures the same mechanism.

Reference answer: every stored pair is added into the same weight matrix as every other pair. With few pairs, one pair's signal dominates and the cue retrieves it cleanly. As more pairs share that matrix, the sum of everyone else's contributions acts as noise on top of the pair you're probing — so accuracy doesn't fail because the memory "runs out of room", it fails because cross-talk from other patterns grows smoothly and continuously. There is no wall and no sudden knee here: this demo does one direct matrix-vector readout, so the signal-to-noise ratio — and therefore accuracy — degrades gradually with N the whole way. (A sharp collapse only shows up in the classical iterative Hopfield network, which repeatedly feeds its own output back in; that's a different, stronger dynamic than the single-pass readout used here.)

Limitation & common misconception

This toy uses random bipolar vectors and a plain outer-product rule — it is not an implementation of BDH. It exists only to make the underlying principle (shared capacity → cross-talk) tangible and falsifiable: drag N up with noise at 0% and watch accuracy decline smoothly and continuously — there is no sudden cliff at any particular N for this single-shot readout, which matches the theoretical curve's shape (a gradually widening gap from 100%, not a step function). A common misconception is that associative memories "fill up" and then reject new writes — in fact they never refuse a write; every pattern degrades all stored patterns a little more, including old ones, which is why interference (a continuous cost, not a hard limit) is the failure mode. A second, related misconception worth flagging explicitly: the well-known "≈0.14×d" Hopfield capacity figure (shown for reference in the stats panel above) describes a different dynamic — an iteratively-converging Hopfield network — and should not be read as the point where this specific single-shot demo breaks; conflating the two is an easy mistake even for people who already know the classical result.

Where this shows up in BDH and BDH-CQ

Dragon Hatchling (BDH) — Pathway's Post-Transformer architecture — implements the same principle at the level of synapses rather than a single matrix. Attention is reformulated as synaptic memory that updates through local, Hebbian-style writes as the model reads, with roughly 5% of neurons active at any moment (sparse, non-negative activity) and individual synapses reported to respond to recognisable semantic concepts rather than raw tokens. The toy weight matrix above is a simplified, single-layer stand-in for that idea: a shared substrate that many associations write into, not a lookup table with one slot per fact.

BDH-CQ (the in-context-learning system built on the same family) makes the fast-weight connection explicit: as demonstrations are ingested, they continuously update a recurrent contextual memory while the model's trained parameters stay fixed — the paper explicitly relates this contextual state to attention, fast-weight memory, and linear-attention views of association, with the special case where state accumulates additively per demonstration, i.e. the same "write more, share the substrate" mechanic explored above. Unlike this toy demo, BDH-CQ's memory is read through iterative latent computation rather than a single matrix–vector product, and the paper reports emergent limits (e.g. on operation composition and ordering) rather than a clean Hopfield-style capacity curve — the analogy holds for the accumulate-and-interfere mechanic, not for every downstream capability.

Outside Pathway: the same "shared substrate, accumulate-and-interfere" idea is active well beyond BDH — Google Research's Titans (2024) explicitly interprets a Transformer's key/value pairs as an associative memory block and adds a gradient-based, test-time-updated neural memory on top of it. This is independent, third-party corroboration that the mechanism this page teaches is a live research direction, not a framing unique to Pathway's papers.
